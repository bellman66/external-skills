# todo

## 무엇을 하나

- 마크다운 TODO 파일을 `## 섹션 → ### 항목 → - [ ] 작업` 구조 그대로 `tree` 모양으로 그린다.
- 행 끝의 `✓ + ✎ ×` 로 완료·추가·수정·삭제한다. 고른 행은 버튼이 행 밑 한 줄(`x: ✓완료  a: +하위  e: ✎수정  d: ×삭제`)로 내려가 좁은 창에서도 다 보인다. 조작은 즉시 파일에 써진다. 손대지 않은 줄은 글자 하나 바뀌지 않는다.
- 항목(###)을 완료하면 `## 완료` 섹션 끝으로 옮기고 제목 뒤에 `(완료 YYYY-MM-DD)` 를 붙인다. `↩` 로 되돌린다.
- 파일을 2초마다 감시해 밖에서 고치면 창이 따라온다. 창의 쓰기와 겹치면 파일 쪽이 이긴다.
- 세션 시작 시 진행 중 항목을 시스템 프롬프트 끝에 붙여, "2번 끝났어" 같은 말이 파일을 안 보고도 통한다.

## 패널 프레임

창은 옆의 대화와 한눈에 구분되게 제 프레임을 두른다. 첫 줄은 제목 띠 — 강조색 블록의
` TODO `, 옆에 용도, 오른쪽 끝에 `n/m 완료` 와 `q: ×닫기` — 이고 그 밑에 가로줄이 간다.
도킹(144열 이상)이면 몸통 전체를 강조색의 굵은 테두리로 두르고, 인라인이면 호스트가 이미
테두리를 그리므로 띠만 그린다. 안쪽의 흐린 둥근 상자가 섹션이다.

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  TODO  할 일 목록             0/6 완료 q: ×닫기 ┃
┃ ────────────────────────────────────────────── ┃
┃                                                ┃
┃ ╭────────────────────────────────────────────╮ ┃
┃ │ ░░░░░░░░░░░░░░░  남은 작업 6                │ ┃
┃ │ ~/workspace/memos/TODO.md          p: 경로 │ ┃
┃ ╰────────────────────────────────────────────╯ ┃
┃ ╭────────────────────────────────────────────╮ ┃
┃ │ § 진행 중                      6/6 남음  + │ ┃
┃ │ ├── ▾ 3. 민감정보 Enum 분리   1/1  ✓ + ✎ × │ ┃
┃ ╰────────────────────────────────────────────╯ ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

## 파일 형식

```markdown
# TODO

## 진행 중

### 1. 통마데 전달 자료
- 대상/기한: (미정)          ← 메모 줄: 체크 대상 아님
- [ ] API 명세 정리
- [x] ERD 초안

## 완료
```

제목에 `완료` 또는 `done` 이 든 섹션이 완료 섹션이다. 없으면 첫 완료 때 만든다.

## 시작하기

```
git clone https://github.com/bellman66/external-skills
claude --plugin-dir ./external-skills/todo
```

세션이 열리면 창이 자동으로 뜬다(터미널 144칸 이상). 좁으면 `/todo` 로 연다.
`/todo` 는 토글이다. 열려 있으면 닫고, 닫혀 있으면 연다(`/todo on` · `/todo off` 로 명시해도 된다).
`/todo` 나 `ctrl+x x` 로 닫아 두면 다음 세션에도 자동으로 뜨지 않는다. `/todo` 로 다시 열면 그때부터 또 자동으로 뜬다.
기본 파일은 `~/workspace/memos/TODO.md` 이고, 헤더의 `p: 경로` 로 바꾸면 다음 세션에도 유지된다.

## 창 쓰는 법

| 조작 | 뜻 |
| --- | --- |
| `ctrl+x tab` | 창에 키보드 포커스 |
| 헤더 `×닫기` / `q` / `/todo` | 창 닫기 (다음 세션에도 안 뜸) |
| `Tab` / `Shift+Tab` / 클릭 | 행 고르기(커서) — Tab 한 번에 한 행, 행 끝 버튼은 건너뛴다 |
| `Enter` | 체크박스 토글, 항목은 접기/펼치기, 완료 섹션은 펼치기/접기 |
| 행 끝 `✓` / `x` | 완료(항목) · 체크(작업) · `↩` 되돌리기 |
| 행 끝 `+` / `a` | 그 밑에 작업 추가 (섹션 줄의 `+` / `n` 은 항목 추가) |
| 행 끝 `✎` / `e` | 글 수정 (체크 상태·들여쓰기·완료 날짜는 유지) |
| 행 끝 `×` / `d` | 삭제 — 두 번 눌러 확정 (첫 번째 뒤 그 버튼만 `×진짜 삭제` 로 밝아진다) |
| 완료 섹션 `×비우기` / `d` | 완료 섹션 항목 전부 삭제 — 두 번 눌러 확정 (`×진짜 비우기(N)`) |
| `f` `c` `r` `p` | 전부 접기/펼치기 · 완료 목록 보기 · 새로고침 · 경로 변경 |
| `Esc` | 입력창·한 번 누른 삭제/비우기를 거두고 원래대로 |

오류는 보이지 않는다: 밖에서 파일이 바뀌어도 누른 줄을 원문으로 다시 찾아 반영하고, 그 줄이 사라졌으면 조용히 다시 읽기만 한다. 파일이 없으면 `+ 첫 항목 추가`(`n`)가 뜨고 첫 추가가 파일을 만든다. 추가·수정·삭제 뒤 커서와 포커스는 새 줄(삭제면 바로 위 줄)에 남는다.

입력창은 대상 행 바로 아래에 뜬다. 첫 줄에 `×취소` `✓저장`, 그 밑에 필드. 필드 폭을 넘는 글은 필드 밑에 접어서 전부 보여 준다. 비우고 Enter, `×취소`, `Esc` 모두 취소.

## 개발

```
claude plugin validate todo
claude plugin test todo
```

`hooks/todo-md.ts` 가 파서·직렬화·조작(순수 함수), `hooks/register.tsx` 가 창과 이벤트다.

## 한계

- 섹션(##) 제목은 창에서 못 고친다. 파일에서 직접 바꾼다.
- 마우스 클릭은 전체화면 터미널에서만 전달된다. 인라인 창에서는 Tab/Enter 로 같은 버튼을 누른다.
- 접기 상태는 세션 안에서만 기억한다.
